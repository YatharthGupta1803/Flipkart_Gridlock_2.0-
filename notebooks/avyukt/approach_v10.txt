2. SPATIOTEMPORAL KINEMATICS & THE INTERACTION KEY
--------------------------------------------------------------------------------
Urban traffic flow does not obey generic, city-wide rules; it is highly localized 
to specific intersections at specific hours. The feature matrix was engineered to 
capture this exact resolution:

* The Golden Feature (Geo-Time Interaction): The raw 6-character geohash and the 
  15-minute time slot are concatenated into a single interaction key 
  (e.g., `qp02z1_45`). This allows the models to learn the exact historical 
  rush-hour profile of a specific microscopic location, rather than relying on 
  broad, inaccurate spatial aggregations.
* Continuous Temporal Kinematics: Discrete timestamps are projected onto a 
  continuous 2D plane using sine and cosine transformations for both hours and 
  minutes. This mathematically resolves the "midnight cliff" anomaly, allowing 
  tree models to recognize 23:45 and 00:00 as physically adjacent timebounds.
* Geometric Spatial Decoding: Base-32 alphanumeric grid codes are decoded into 
  continuous latitude and longitude floating-point arrays to provide underlying 
  geometric context for spatial interpolation.


3. LEAK-FREE TARGET ENCODING (HIGH-CARDINALITY GOVERNANCE)
--------------------------------------------------------------------------------
The creation of the `geo_time_interaction` key introduces tens of thousands of 
unique categorical variables. Passing this directly into a decision tree results 
in catastrophic overfitting.

* Out-of-Fold (OOF) Spatial Mapping: To convert this high-cardinality string into 
  a usable mathematical constraint, the pipeline employs a strict 5-Fold Target 
  Encoder. The historical demand for any given `geo_time_interaction` is 
  calculated exclusively using cross-validation folds that the model was NOT 
  trained on. This guarantees zero look-ahead bias and mathematically prevents 
  the trees from memorizing the training target.


4. ALGORITHMIC MULTI-ENGINE CORE
--------------------------------------------------------------------------------
Because the target variable is tightly bounded as a continuous fraction [0.0, 1.0], 
the ensemble reverts to standard, highly stable Root Mean Squared Error (RMSE) 
objectives, deploying three distinct gradient-boosted topologies:

1. LightGBM (Leaf-wise Growth): Configured with an aggressive `num_leaves=128` 
   and constrained `max_depth=8`. The highly efficient leaf-wise splitting captures 
   deep, high-order feature interactions across the target-encoded temporal grids.
2. XGBoost (Depth-wise Growth): Utilizes a level-wise growth strategy capped at 
   `max_depth=7`. This regularizes tree depth uniformly, providing a structurally 
   conservative baseline that prevents localized overfitting on extreme traffic spikes.
3. CatBoost (Symmetric Trees): Employs symmetric oblivious trees where the same 
   splitting criteria is applied across an entire layer, acting as a robust 
   mathematical regularizer against localized spatial noise.


5. DIRECT METRIC OPTIMIZATION & PLATFORM ASSEMBLY
--------------------------------------------------------------------------------
Instead of relying on arbitrary weight heuristics, the pipeline optimizes the 
ensemble blend identically to the platform's backend metric:

* R² Maximization Solver: Independent Out-of-Fold (OOF) prediction arrays from 
  the 5 validation sets are passed into a SciPy Nelder-Mead Simplex. The solver 
  explicitly traverses the weight space (w1, w2, w3) to find the absolute maximum 
  for the exact grading equation: max(0, 100 * r2_score).
* Physical Bounds Enforcement: Traffic capacity cannot drop below zero or exceed 
  100%. The final inference array applies an absolute continuous clip [0.0, 1.0] 
  before being bound to the test index and written to disk, guaranteeing 100% 
  evaluation schema compliance.
