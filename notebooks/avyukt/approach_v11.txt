2. MINIMALIST INGESTION & DATA GOVERNANCE
--------------------------------------------------------------------------------
Traditional gradient boosting requires continuous numeric inputs, forcing data 
scientists to mathematically transform categorical variables (e.g., Geohashes, 
Road Types). This pipeline intentionally skips these transformations to preserve 
the raw physical signals:

* Chronological String Parsing: The `timestamp` column is split into discrete 
  `raw_hour` and `raw_minute` strings. They are explicitly NOT converted to 
  integers or sine/cosine waves. This forces the model to treat "17:45" as a 
  distinct categorical state of traffic, exactly as a human would experience it.
* Strict Categorical Casting: All environmental variables (Weather, RoadType) 
  and spatial identifiers (Geohash) are safely imputed for missing values and 
  locked as string data types prior to compilation.


3. NATIVE CATEGORICAL EMBEDDING
--------------------------------------------------------------------------------
The core of this architecture relies on CatBoost's proprietary algorithm for 
processing categorical features during training:

* On-the-Fly Target Statistics: Instead of calculating Out-of-Fold (OOF) target 
  encodings manually (which risks data leakage if the splits are not perfectly 
  isolated), the engine computes dynamic, randomized permutations of target 
  statistics natively within the tree-building process.
* Deep Feature Combinations: The engine autonomously evaluates combinations of 
  raw categories (e.g., automatically discovering that `Geohash=qp02z1` AND 
  `Weather=Rain` AND `raw_hour=17` equals a massive traffic spike) without 
  requiring the manual construction of high-cardinality interaction keys.


4. SYMMETRICAL OBLIVIOUS TREES (ALGORITHMIC CORE)
--------------------------------------------------------------------------------
The predictive engine evaluates the matrix using a single, highly optimized 
gradient boosting topology:

* Oblivious Tree Structure: Unlike LightGBM (which grows leaf-wise) or XGBoost 
  (which grows depth-wise asymmetrically), this engine applies the exact same 
  splitting condition across an entire depth level of the tree.
* Inherent Regularization: This symmetrical topology is mathematically resistant 
  to overfitting. It acts as a strict regularizer, preventing the model from 
  memorizing isolated noise in the training set and ensuring that the autonomous 
  categorical embeddings generalize cleanly to the hidden evaluation data.
* Hyperparameter Configuration: The model is constrained to `depth=8` and a 
  slow `learning_rate=0.03` over 3,500 iterations, maximizing the extraction 
  of subtle spatio-temporal trends.


5. METRIC EVALUATION & PLATFORM ASSEMBLY
--------------------------------------------------------------------------------
The pipeline maintains rigorous validation standards while outputting directly 
to the platform's required schema:

* K-Fold Validation: The matrix is evaluated across 5 randomized folds, ensuring 
  the Terminal R² Score accurately reflects the model's out-of-sample capability.
* Physical Bounds Enforcement: Because traffic capacity represents a physical 
  ratio, it cannot drop below zero or exceed 100%. The final inference array 
  applies an absolute continuous clip [0.0, 1.0].
* Dynamic Schema Mapping: The bounded predictions are merged directly with the 
  evaluation `Index` and exported without standard index tracking, guaranteeing 
  100% compliance with the grading platform's schema.
